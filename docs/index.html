Deal Finder for iPhone

A Safari bookmark that finds promo codes at checkout, tries each one, and keeps the one that saves the most. No app and no account. It keeps no record of what you browse. Your code history stays on your phone.

1. Copy the bookmark code

Copy didn't work? Select it by hand

2. Save it as a bookmark

  1. On this page, tap Share (on iOS 26, tap ••• first), then Add Bookmark, then Save.
  2. Open Bookmarks (the open book, or ••• then Bookmarks on iOS 26), tap Edit, and tap the bookmark you just made.
  3. Change the name to Deal Finder.
  4. Tap the address under the name, clear it, and paste. Tap Done.

3. Use it at checkout

  1. Go to the store's cart or checkout page, where the promo code box is.
  2. Tap the address bar, type Deal Finder, and tap the bookmark in the list.
  3. A Deal Finder card shows the codes it found. Tap Try. It tries each code and leaves the best one applied.

Where the codes come from

  • The checkout page itself.
  • The store's own homepage and promo pages, where its robots.txt allows.
  • The open codes list, refreshed daily from stores' own sites.
  • Codes that worked for you on that store before, saved on your phone only.

No affiliate links. No coupon sites. It never enters payment details or places an order.

What it can't do on a phone

  • It runs only when you tap it. There are no price-drop alerts like the desktop extension.
  • A few checkouts block bookmarks from running. If nothing appears, that store blocks it.
  • On stores where Apply reloads the page, the card goes away. Tap Deal Finder again within 3 minutes and it picks up where it stopped.
  • To get the list of shared codes, your phone downloads a public file from GitHub. GitHub can see the store's address in that request, like any site that loads a file from it.
  • Amazon, Walmart and Target: it tries codes on the page and your own, but doesn't read their other pages.
